# CYD Love Gift 💗

هدية رومانسية على ESP32-2432S028R (Cheap Yellow Display).

## الصفحات (من الشريط السفلي)
- **Home**: قلب ينبض مع قلوب تطير، اسمها، عدّاد "X days of loving you". لمس القلب = انفجار قلوب.
- **Notes**: رسائل حب، لمسة = رسالة جديدة.
- **Coupons**: 6 قسائم حب (تكشف ثم "Enjoyed")، تُحفظ بعد إطفاء الجهاز.
- **Game**: لعبة التقاط القلوب (القلب الذهبي +5، القلب المكسور يخصم حياة).

لمسات إضافية: الـ LED يبض بنبضة قلب وردية، والشاشة تخفّ تلقائياً في الغرفة المظلمة.

## التخصيص: ملف `src/config.h`
الاسم، العنوان، تاريخ البداية، الرسائل، القسائم. ولو حطيت واي فاي البيت يضبط الوقت مرة وحدة عند التشغيل ثم يُطفأ.

## التشغيل
VS Code + PlatformIO → Upload.

## حل المشاكل
| المشكلة | الحل |
|---|---|
| شاشة بيضاء | غيّر `-DILI9341_2_DRIVER=1` إلى `-DILI9341_DRIVER=1` |
| ألوان معكوسة | فعّل `-DTFT_INVERSION_ON=1` |
| أحمر/أزرق مقلوبين | فعّل `-DTFT_RGB_ORDER=TFT_BGR` |
| مقلوبة | `setRotation(3)` للشاشة واللمس |
| اللمس غير دقيق | عدّل `TS_MIN/MAX` |
